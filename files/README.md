# مجلد الملفات

هنا تُرفع ملفات المواد الفعلية (PDF, Word, PowerPoint, Excel, صور، فيديو).

## الخطوتان

**1) ارفع الملف** داخل مجلد المادة المناسب:

| المادة | المجلد |
|---|---|
| الذكاء الاصطناعي وتحليل البيانات | `files/ai-data/` |
| الثقافة القانونية والتنظيمية | `files/legal-regulatory/` |
| حوكمة الأمن السيبراني | `files/cybersecurity-governance/` |
| الابتكار وإدارة المشاريع | `files/innovation-project-management/` |
| إدارة المخاطر | `files/risk-management/` |

**2) اربط الملف** في ملف بيانات المادة `data/subjects/<المادة>.js` بوضع المسار مكان `null`:

```js
{ type: 'pdf', label: 'ملف المحاضرة (PDF)', url: 'files/ai-data/lecture-01.pdf' }
```

المسار نسبي من جذر المشروع: بلا `/` في أوله وبلا رابط GitHub كامل.

## قواعد التسمية

- أسماء إنجليزية بلا مسافات: `lecture-01.pdf` ✅ — `المحاضرة الأولى.pdf` ❌
- استخدم الشرطة `-` بدل المسافة أو الشرطة السفلية.
- نمط مقترح: `lecture-01.pdf` · `summary-01.pdf` · `assignment-01.docx` · `handbook.pdf`

## حدود الحجم

- الرفع من موقع GitHub: حتى 25 ميجابايت للملف.
- الحد الأقصى المطلق: 100 ميجابايت.
- الفيديوهات الكبيرة: ارفعها على YouTube أو Google Drive وضع الرابط الكامل في `url` بدل المسار.

## أين يوضع كل نوع؟

| الحقل في ملف البيانات | الاستخدام |
|---|---|
| `lectures[].files[]` | ملفات تابعة لمحاضرة معيّنة |
| `summaries[].files[]` | ملفات الملخصات |
| `assignments[].files[]` | ورقة المهمة أو نموذج التسليم |
| `resources[]` | ملفات عامة تظهر في قسم «الملفات والموارد» |
| `references[]` | الكتب والأبحاث والمواقع الرسمية |

`type` المتاح: `pdf` · `docx` · `pptx` · `xlsx` · `image` · `video` · `link`

> الملف الذي قيمته `url: null` يظهر في المنصة بعبارة «قريباً» بدل رابط مكسور — وهذا سلوك مقصود.
